# ONTOLOGY.md — Личный корпус (ЛЧ)

Типы сущностей и связи между ними. Растёт из практики.
Любое добавление нового типа — решение с датой
и обоснованием в DECISIONS.md.

## Текущие типы сущностей

- ENTITY — корневой тип. Любой объект, который ещё
  не получил более точной классификации. Используется
  для первичной фиксации raw-данных без раздутия
  онтологии.

### Ограничение

ENTITY не должен оставаться без решения о типизации
неопределённо долго. Практический ориентир — 30 дней
с момента создания. По истечении срока требуется явное
решение (типизация или обоснованное сохранение статуса
ENTITY), фиксируемое в DECISIONS.md.
