# KLAN

## Що це

Закритий персональний корпус даних про себе (оператора)
і пов'язаних контекстів: родина, документи, медична
історія, оточення.

Призначення:

- структуроване зберігання і накопичення;
- інтерактивний запит через LLM-агентів;
- крос-аналіз із збереженням периметра приватності.

## Що це не

- Не продукт.
- Не система стеження за третіми особами.
- Не претендує на повноту. Відсутність даних = UNKNOWN.
- Не публічний репозиторій.

## Периметр приватності

Чутливі дані (PII, medical, family identifiers)
не передаються у зовнішні API без явного рішення
оператора і попереднього маскування. Локальні моделі —
повний доступ.

- meta/open-questions.md — що не вирішено.

## Роль оператора

Оператор — повноцінний вузол. Його рішення логуються.
Перевизначення раніше зафіксованого FACT позначається
OPERATOR_OVERRIDE.

## Відношення до зовнішнього контуру

LAB (nova-cortex-lab) — зовнішня основа методу.
Не джерело контенту, не частина KLAN.
Зміни в LAB не відображаються автоматично.
Передача даних з KLAN у LAB — тільки за явним рішенням
оператора.

Envoy — паралельна пілотна гілка.
Спільне джерело (LAB), спільний контур — різна природа
даних. Обмін між KLAN і Envoy за замовчуванням
не передбачається.

## Правила

- Append-only з процедурою редагування.
- Кожна зміна — з датою і обґрунтуванням.
- Приватність — технічне обмеження, не декларація.
- Якщо даних немає — UNKNOWN, не здогад.
