# ЛИЧНЫЙ КОРПУС (ЛЧ)

## Что это

Закрытый персональный корпус данных о себе (операторе)
и связанных контекстах: семья, документы, медицинская
история, окружение.

Назначение:

- структурированное хранение и накопление;
- интерактивный запрос через LLM-агентов;
- кросс-анализ при сохранении периметра приватности.

## Что это не

- Не продукт.
- Не система слежки за третьими лицами.
- Не претендует на полноту. Отсутствие данных = UNKNOWN.
- Не публичный репозиторий.

## Периметр приватности

Чувствительные данные (PII, medical, family identifiers)
не передаются во внешние API без явного решения оператора
и предварительного маскирования. Локальные модели —
полный доступ.

## Как читать

- Начни с AGENT.md. Там — точка входа для LLM-агента.
- CONCEPT.md — не канон. Рабочий документ.
- CURRENT_STATE.md — что есть, чего нет, куда идём.
- DECISIONS.md — журнал, append-only.
- REDACTIONS.md — журнал редикций, append-only.
- meta/open-questions.md — что не решено.

## Роль оператора

Оператор — полноценный узел. Его решения логируются.
Переопределение ранее зафиксированного FACT помечается
OPERATOR_OVERRIDE.

## Отношение к внешнему контуру

LAB (nova-cortex-lab) — внешняя основа метода.
Не источник контента, не часть ЛЧ.
Изменения в LAB не отражаются автоматически.
Передача данных из ЛЧ в LAB — только по явному решению
оператора.

Envoy — параллельная пилотная ветка.
Общий источник (LAB), общий контур — разная природа данных.
Обмен между ЛЧ и Envoy — не предполагается по умолчанию.

## Правила

- Append-only с процедурой редикции.
- Каждое изменение — с датой и обоснованием.
- Приватность — техническое ограничение, не декларация.
- Если данных нет — UNKNOWN, не догадка.
